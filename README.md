An Android app that uses a quantized ONNX model to segment live camera frames into 10 classes (e.g., person, sidewalk), then overlays the resulting mask for real-time visual feedback.
It constantly monitors the user’s lateral position, vibrating a belt when they drift right or left to help them stay centered, and delivers turn-by-turn voice guidance via Google Maps.
Leveraging a pinhole-camera approach, it also estimates distances to nearby cyclists and pedestrians for enhanced situational awareness.
